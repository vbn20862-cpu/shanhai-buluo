# 山海部落

以臺灣全島為地圖、以原住民族為主題的多人連線部落經營遊戲（橫式手機網頁）。名稱為暫定。

七個階段（部落經營、連線與掛機、對戰、世界互動、任務與英雄、平衡、上線準備）都做完了，程式已經可以公開上線；之後是一族一族加入其他族群。方向、製作計畫與進度請看 [`docs/DESIGN.md`](docs/DESIGN.md)。

## 在電腦上啟動

需要先安裝 [Node.js](https://nodejs.org/)（18 以上）。第一次要先安裝套件：

```bash
npm install
```

啟動遊戲（把「自己取的密碼」換成你要的後台密碼）：

```bash
ADMIN_PASSWORD=自己取的密碼 npm start
```

- 遊戲：用瀏覽器開 http://localhost:3000
- 後台：http://localhost:3000/admin ，輸入上面的密碼
- 不需要後台時，直接 `npm start` 也可以

### 遊戲節奏

連線版預設是**正式節奏（20）**：產量是快速試玩的二十分之一，建設、訓練、路程、保護的時間是二十倍，適合連玩好幾天。想快速試玩，啟動時加上 `PACE=1`：

```bash
PACE=1 ADMIN_PASSWORD=自己取的密碼 npm start
```

節奏也可以隨時在後台的「數值調整」切換；改過之後會記在存檔裡，下次啟動沿用。

### 後台可以做什麼

- **總覽**：所有部落的進度、各族統計、對戰紀錄、族群關係、全島地圖，以及伺服器的狀況（運作多久、記憶體、連線數、流量、上次存檔與備份）。可以下載存檔、馬上備份一次。部落清單每一列的「調整」可以幫那個部落加減物資、給保護時間、改名，或移除部落（處理不當名稱與灌水）。
- **數值調整**：遊戲節奏、產量、花費、各族產量倍率、兵種與英雄的強弱、圍籬與瞭望台、獨特建築的效果。改完按「套用修改」馬上生效，也可以全部還原成預設。
- **模擬對戰**：讓電腦自動打幾千場，看任兩族之間的勝率是不是落在 45%～55%。可以先用還沒套用的修改試算，再決定要不要套用。
- **操作紀錄**：後台改過什麼都會留下紀錄。

## 用兩支手機一起玩

1. 電腦和手機連到同一個 Wi-Fi。
2. 在 Mac 的「系統設定 → Wi-Fi → 詳細資訊」找到電腦的 IP 位址（例如 192.168.1.23）。
3. 手機瀏覽器開 `http://那個IP位址:3000`，把手機橫放。

每支手機會各自建立一個部落，在「地圖」分頁可以看到並拜訪對方。進度存在電腦的 `data/world.json`，想從頭來過就先停掉伺服器再刪掉這個檔案。

## 放到網路上（Railway）

遊戲需要一臺一直開著、存檔不會消失的主機。目前的做法是放在 [Railway](https://railway.com)，每月約 5 美元。

### 第一次部署

1. 用 GitHub 帳號登入 Railway，New Project → Deploy from GitHub repo → 選 `shanhai-buluo`。
2. 服務的 Settings → Scale → Regions 選 Southeast Asia（Singapore）。要在掛硬碟之前選。
3. 服務的 Variables 分頁新增變數：

   | 名稱 | 內容 | 一定要嗎 |
   |---|---|---|
   | `ADMIN_PASSWORD` | 自己取的後台密碼，取長一點、不要和別的地方共用 | 要 |
   | `DATA_FILE` | `/data/world.json` | 要 |
   | `JOIN_CODE` | 自己取的邀請碼。有設定時，要輸入邀請碼才能建立部落（封閉測試用）；公開時把這個變數刪掉 | 看情況 |
   | `CONTACT_TEXT` | 顯示在遊戲裡「關於這個遊戲」最後的一句話，例如「意見回饋請寄到……」 | 不用 |

   遊戲節奏不用設定，預設就是正式節奏；要改的話到後台調整。
4. 新增一個 Volume 掛到這個服務，Mount path 填 `/data`。
5. 服務的 Settings → Deploy → Healthcheck Path 填 `/healthz`。這樣每次更新，Railway 會等新版本真的能用了才切換過去。
6. 按 Deploy，等它變成成功。
7. 服務的 Settings → Networking → Generate Domain，得到 `https://xxxx.up.railway.app`，這就是遊戲的網址；後台是網址後面加 `/admin`。

之後每次把程式推上 GitHub 的 `main`，Railway 會自動更新。更新時玩家會短暫斷線，幾秒後自動接回，存檔會保留。

### 想用自己的網址

1. 先向網域商買一個網域（例如 Cloudflare、Namecheap、Gandi），一年大約新臺幣三、四百元起。
2. Railway 服務的 Settings → Networking → Custom Domain，填想用的網址。建議用子網域，例如 `play.你的網域`。
3. Railway 會給你兩筆設定（一筆 CNAME、一筆 TXT），到網域商的 DNS 設定頁照著新增。**兩筆都要加**，只加一筆網址不會通。
4. 等幾分鐘到幾小時，Railway 顯示驗證成功就可以用了，憑證（https）會自動處理。

用 Railway 給的 `up.railway.app` 網址也可以直接公開，不一定要買網域。

### 公開上線前的檢查表

- [ ] 後台密碼夠長，而且只有你知道。
- [ ] 進後台看一眼：「伺服器」那一格有在存檔、有備份；「數值調整」的遊戲節奏是你要的（正式是 20）。
- [ ] 自己用手機實際玩一輪：建立部落、蓋房子、把「部落代碼」記下來，換一臺裝置輸入代碼，確認接得回來。
- [ ] 決定要不要邀請碼。公開的話，把 `JOIN_CODE` 這個變數刪掉。
- [ ] 文化內容還沒有經過族人審閱（遊戲裡的「關於這個遊戲」有寫明）。正式對外宣傳之前，建議先請各族的族人或專家看過；最需要確認的是排灣的英雄「巴里」。
- [ ] 下載一份存檔留著（後台 → 總覽 →「下載存檔」）。

### 上線之後

- **備份**：伺服器每 20 秒存檔一次，另外每 6 小時多留一份備份（留最新的 8 份，放在 `/data/backups`）。存檔萬一壞掉，重新啟動時會自動改用最新的備份。想自己留一份，到後台按「下載存檔」。下載的檔案裡有所有玩家的部落鑰匙，不要外流。
- **玩家換裝置**：遊戲裡「部落」分頁最下面有「換裝置繼續玩」，可以看到自己的部落代碼、複製連結。在另一臺裝置打開連結，或在開始畫面輸入代碼，就會接回同一個部落。清掉瀏覽器資料又沒有記下代碼的話，部落就找不回來了。
- **防灌水**：同一個網路位置每小時最多建立 5 個新部落、最多 20 個連線；玩家部落的總數上限是 300。要調整可以在 Variables 加 `JOINS_PER_HOUR`、`MAX_CONN_PER_IP`、`MAX_VILLAGES`。
- **不當的名稱或灌水的部落**：後台的部落清單按「調整」，可以改名或移除。
- **人變多的時候**：後台「伺服器」那一格看得到記憶體和每秒送出的流量。實測 280 人同時在線時，記憶體約 150 MB、每人每秒約 0.1 KB，Railway 的基本方案夠用。

## 其他指令

```bash
npm test
```

```bash
npm run build:solo
```

```bash
npm run sim
```

第一個是跑規則的自動測試，第二個是把遊戲打包成單一檔案（單機預覽頁用），第三個是用預設數值自動模擬對戰、列出各族互打的勝率（改了兵種或英雄的數值之後跑一次，確認還是公平）。

```bash
npm run build:art
```

把 `art/` 裡的美術素材（建築、圖示）打包給遊戲使用。換了素材之後跑一次，再跑 `npm run build:solo`。
