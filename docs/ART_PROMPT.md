- **現在要用的是「第四包：魯凱族、卑南族」**（下面第一段）。整段貼進 Claude Design。兩族的獨特建築、獨特兵種、英雄、特產圖示還在等文化內容確認，確認後會另外給一段補充的提示詞。
- 請貼在做前面幾包的同一個 Claude Design 專案裡（例如「山海部落 美術設計」那張畫布），風格才會一致；如果是新的對話，請把 `art/` 資料夾和遊戲截圖一起附上。
