# 美術設計用的提示詞

把下面「主要提示詞」整段貼進 Claude Design，並附上遊戲現在的截圖當參考。做出來之後，把設計的連結或匯出的 SVG 檔交回來，就可以接進 `public/art.js`。

## 主要提示詞

```
請你擔任這款遊戲的美術總監，幫我做一套可以直接交給程式使用的美術設計。

【專案】
《山海部落》（暫定名）：以臺灣全島為地圖、以臺灣原住民族為主題的多人連線部落經營遊戲，目的是文化推廣加上大眾娛樂。
- 平臺：橫式手機網頁，主要尺寸 844×390，也要能放大到平板和電腦。
- 背景：虛構的「南島時期」，島上只有原住民族。
- 玩法：選一個族群的區域落腳 → 拓荒、蓋房子、分配族人採集 → 訓練戰士，出征和防守（三條路的對戰）→ 交易、結盟 → 每一族有一條以神話為底的任務線。
- 第一版開放四族：泰雅、布農、阿美、排灣。之後會一族一族加到 17 族，所以設計要能延伸。

【現況】
目前所有畫面都是程式畫的向量圖（SVG），扁平色塊、深色介面，我附上了幾張截圖。請在這個基礎上把美術做得更有質感、更有辨識度，但維持「向量、扁平、色塊」的方向——要在手機瀏覽器上跑得順，也方便之後增加族群。

【請你做的東西】（放在同一份設計裡，分成幾個畫板）
1. 風格指南：整體調性、配色、線條與陰影的規則、字體、圖示風格，以及四族各自的色彩與材質語彙（一眼看得出是哪一族，但不靠專屬紋樣）。
2. 部落場景：斜上方俯視的等角視角。四族各一張完整示意，包含中央建築、幾棟建築、田、小路、圍籬和周圍的山林。泰雅、布農、排灣在山區，旁邊有溪；阿美在海岸，有沙灘和海。
3. 建築圖組：四族 × 10 種建築（見下表），每一棟是一個獨立的 SVG。
4. 人物：勇士（拿矛）、弓手（拿弓）、四族的獨特兵種、四位「傳說英雄」、一般族人。在畫面上只有 30 到 40 像素高，小尺寸也要認得出來。
5. 對戰畫面：側面橫幅，比例 1000×300。三條橫向的路由上到下是山徑、正門、溪谷；進攻方從左邊的山林來，防守方在右邊，後面有圍籬、瞭望台和部落。請畫出「待命」「衝鋒」「射箭」「蹲下重整」「往後退場」五種姿勢。
6. 圖示（單色、16×16 起跳也清楚）：糧食（小米）、建材、四族的特產、族人、戰士、繁榮、保護、共聚（營火）、任務（書），以及三種對戰指令：衝鋒、掩護射擊、重整。
7. 遊戲標誌，加上一張橫式主視覺（開始畫面用）。

【四族的建築】（括號裡是外觀重點；沒有寫的請用簡化造型，不要自己編文化細節）
共同的十種：中心建築、家屋、小米田、建材採集場、特產建築、倉庫、訓練場、瞭望台、圍籬、獨特建築。

- 泰雅族（北部山區；竹、木、茅草）
  中心：領袖家屋／家屋：半穴居的木屋或竹屋／建材：竹木堆／特產：織布屋，屋旁晾著布（只畫一般條紋）／倉庫：架高的穀倉，柱子上有防鼠板／圍籬：竹圍／獨特：望樓——用很多根原木撐起來的高臺，有梯子和一圈走道，比一般瞭望台高
- 布農族（中央山脈高處；石板、木頭）
  中心：主屋／家屋：石板牆的家屋／建材：石板和木頭堆／特產：獵寮（山上的工寮），旁邊的架子掛著肉乾／倉庫：小米倉，畫成矮石屋／圍籬：石牆／獨特：石板豬圈——厚石板圍成的矮圈，一角有石板頂，裡面養黑豬
- 阿美族（東部縱谷與海岸；茅草、竹子、木柱）
  中心：聚會所，四面開放的大茅草屋／家屋：茅草屋頂、竹牆／建材：竹木堆／特產：漁寮，架上曬魚／倉庫：架高的穀倉／圍籬：竹圍／獨特：巴拉告——水道裡用竹筒和樹枝搭出來、讓魚蝦棲息的地方
- 排灣族（南部山區；板岩石板）
  中心：頭目家屋，前面有石砌的平臺和一塊立石（立石不刻任何圖案）／家屋：石板屋／建材：石板堆／特產：紅藜田，穗是桃紅色／倉庫：穀倉／圍籬：石牆／獨特：芋頭窯——石板砌的窯，上面搭木架和竹架烘芋頭

人物：
- 獨特兵種：泰雅「山林獵手」（近戰）、布農「獵人」（拿大弓、背箭袋）、阿美「部落青年」（近戰）、排灣「石牆守衛」（拿矛和素面圓盾）。
- 傳說英雄：泰雅「射日的勇士們」（兩三個人一起，拿弓）、布農「射日的父子」（一大一小，拿弓）、阿美「齊心的青年們」（一群青年）、排灣「紅眼睛的巴里」（一個人，戴著遮住眼睛的帽子，不拿武器）。

【配色】
- 介面是深色：底 #14212A、面板 #1C2E38、浮起 #24394A、框線 #30495A、文字 #F2EAD6、次要文字 #9DB0B8、強調金 #E3B341、警示 #F0A48F、正面 #BFE3C4。可以微調，但請維持深色底、米白字、金色強調。
- 四族的代表色：泰雅 #B5483A、布農 #3E8A62、阿美 #2F78C2、排灣 #C9962B。
- 字體：標題用「霞鶩文楷 TC」，內文用「Noto Sans TC」。介面文字是繁體中文。

【技術規格】
- 全部用 SVG 向量，以扁平色塊為主。不要用濾鏡、模糊，也不要大量漸層；每個圖的路徑數量盡量少。
- 等角視角的比例：地面往右下一格是往右 28、往下 14 像素；往左下一格是往左 28、往下 14 像素。
- 每棟建築佔地大約 2.4 × 2.1 格，也就是地面菱形寬約 126、高約 63 像素。以佔地的中心為原點，建築往上長。一般建築高 50 到 80 像素，瞭望台約 105，望樓約 130。
- 每棟建築的顏色請整理成幾個可以替換的變數：屋頂、牆、裝飾色、地面。
- 人物以腳底為原點、面向右。
- 檔名用英文：族群-種類.svg，例如 atayal-center.svg。族群代號是 atayal、bunun、amis、paiwan；建築代號是 center、house、farm、mat、special、storage、barracks、tower、wall、unique。

【一定要遵守的文化原則】
1. 不畫獵首、頭骨、血、倒下或死亡的人。對戰裡輸的一方只會「往後退場」。
2. 各族專屬的紋樣（例如織紋、菱形紋、百步蛇紋、人頭紋、太陽紋）和有身分意義的物品（陶壺、琉璃珠、青銅刀、特定的羽毛頭飾）在取得授權之前都不要畫。裝飾只用一般的條紋和色塊，而且請做成可以單獨開關、之後可以替換的圖層。
3. 不畫紋面，不畫神靈、祖靈、巫師和祭儀的場面。百步蛇不出現。
4. 服裝用簡化的日常樣式，加上族群代表色的頭帶或腰帶來區分，不要畫成祭典盛裝，也不要讓人物看起來像特定的頭目或貴族。
5. 四族要看得出不同（建材、屋型、地景都不一樣），不要畫成同一種籠統的「原住民風」，也不要用美洲原住民或其他地方的造型。
6. 不要用真實人物的長相。
7. 不確定的文化細節請不要自己編：用簡化的幾何造型，並在旁邊標上「待查證」。

【交付】
- 一份風格指南，加上每一項的畫板。
- 可以匯出的 SVG 檔，照上面的檔名。
- 每一族請附一小段說明：用了哪些顏色和材質、哪裡標了「待查證」。
先給我風格指南和「阿美族」的部落場景當樣張，我確認方向之後再做其他三族。
```

## 之後可以接著用的提示詞

確認樣張之後，做其他三族：

```
方向可以。請照同樣的風格和規格，接著做泰雅、布農、排灣三族的部落場景和建築圖組，再做人物、對戰畫面、圖示。文化原則和技術規格都照原本的。
```

想調整風格的時候：

```
請保留現在的構圖和規格，只調整這幾點：（寫上你想改的，例如「顏色再暖一點」「建築的輪廓再圓潤一點」「人物的比例再高一點」）。四族都要一起套用。
```

要交回來給程式的時候：

```
請把所有圖匯出成獨立的 SVG 檔，照「族群-種類.svg」命名，並列出每個檔案的原點位置、寬高，以及可以替換的顏色變數名稱。
```
