# 山海部落：設計方向

> 狀態：**方向已全部確認，依製作計畫分階段製作中**（目前：階段 1）。
> 每個階段做完先給使用者看預覽，確認後才做下一階段。有新的方向要先討論、記進這份文件，再動工。

「山海部落」是暫定名稱。使用者以繁體中文（臺灣用語）溝通，說明要白話、少用技術詞。

## 已確定的方向

| 項目 | 決定 |
|---|---|
| 主題 | 臺灣原住民族，文化推廣與一般大眾娛樂並重 |
| 類型 | 選單式部落經營模擬（採集、建設、訓練），參考部落衝突與世紀帝國的採集建設；不做開放世界 |
| 平臺 | 橫式手機網頁，之後再評估包成 App 上架 |
| 連線 | 多人即時連線，伺服器當唯一裁判 |
| 地圖 | 臺灣全島，自然風格（平滑海岸線、區域是邊界柔和的色塊）；六角格只藏在背後當預設落腳點，一格可以有多個部落 |
| 時空 | 只有原住民族的南島時期，不放閩漢 |
| 衝突 | 部落之間可以出征、搶奪資源 |
| 族群 | 以官方認定的 17 族為準（2026 年 7 月核定西拉雅族為第 17 族），各族要平衡、彼此要有關係，一族一族慢慢開發 |
| 掛機 | 離線前可以設定採集哪些資源等，離線期間照設定累積 |
| 第二款 | 神話故事冒險另外開發，不併進這一款 |
| 製作環境 | 專案放在 GitHub（本專案庫），可以在 MacBook 上用 Claude 桌面版製作，也可以用雲端對話 |
| 時代呈現 | 架空的古代（「很久以前」），不對應特定年代 |
| 沒有族群的格子 | 混合：大部分是無主野地（有獵場、漁場等資源點，可以爭奪），少數是平埔族群的中立聚落（可交易、不能玩也不能打） |
| 誰跟誰打 | 以玩家的部落為單位，同族也能互打，聯盟可以跨族 |
| 族群之間的關係 | 有正向的交流度，也有敵對度 |
| 衝突的程度 | 出征搶物資，加上爭奪野地資源點；部落本身不會被打掉或佔領，只損失物資和一段時間 |
| 平衡方式 | 每族有獨特的兵種或建築（不是全族相同），但整體強度要相當 |
| 領域大小落差 | 強弱不跟領域大小掛鉤；小區域每格容納更多部落、可使用鄰近野地；依照人數，人越少的族群加成越多 |
| 雅美（達悟） | 規則和其他族完全一樣，只是進出蘭嶼都走海路、時間較長 |
| 離線時 | 可以被出征，但有倉庫保護量與戰敗後的保護時間 |
| 長期目標 | 永久世界加排行榜（繁榮度、戰功、聯盟） |
| 第一版開放的族群 | 泰雅、布農、阿美、排灣，其餘陸續加入 |
| 美術風格 | 先用程式畫的扁平向量插畫，素材要做成可以替換，之後換成畫師作品 |
| 紋樣 | 素材做成可替換；開發階段用一般幾何圖形，取得該族或部落授權後才換上專屬紋樣，並且只放在身分正確的地方 |
| 戰利品 | 用珍貴但不神聖的東西（各族特產與工藝品）；神聖物品不當戰利品 |
| 獵首與傷亡 | 先保留「不呈現」；戰敗寫成「撤退」 |
| 任務系統 | 每族有以神話故事為基底的任務，完成後解鎖新物品或新兵種 |
| 部落畫面 | 不用方格。從斜上方俯視的立體場景，像世紀帝國、三國志；建築蓋在融入風景的固定建地上；場景比螢幕大，可以拖曳縮放；操作仍是選單式 |
| 拓荒 | 部落的開發需要拓荒：一開始只有中央一小塊開墾地，外圍是山林，要派人拓荒才有新的建地 |

## 已確認的細節

使用者已確認下面 A 到 F。例外是 A 裡「神靈能不能操控」和新增的兩項，見後面的「待確認」。

**A. 任務系統**
- 每族一條主線，共 5 章，取材自該族的一則神話。每章是一小段故事、一個用經營玩法完成的目標、一份獎勵。
- 目標類型：累積物資、蓋或升級建築、訓練、佔領野地資源點、和別族交易、出征。
- 獎勵（階段 5 定案）：第 1、2 章各給一件「器物」（永久小加成的工具）與物資，第 3 章解鎖獨特建築，第 4 章解鎖獨特兵種，第 5 章解鎖傳說英雄與共聚。各族章數與獎勵強度相同。
- 故事只用公開流傳的版本並標明出處；文字要請族人審閱。
- 採用的神話（階段 5 已查證，細節見「階段 5 的內容」）：布農「與月亮的約定」、泰雅「射日傳說」、阿美「美崙山的巨人（阿里嘎該）」、排灣「紅眼睛的巴里」。

**B. 各族獨特建築與兵種**（使用者認可這份草案；文化依據要再查證）
- 所有族共用勇士、弓手兩種基本兵種，每族另有一棟獨特建築與一種獨特兵種。
- 泰雅：望樓（提早發現來襲、防守加成）／山林獵手（防守時較強）
- 布農：獵寮（野地資源點採集加成）／獵人（強化的弓手）
- 阿美：聚會所的年齡階級（訓練較快）／青年階級（同行人數越多越強）
- 排灣：石板建築（建築耐打、倉庫保護量較高）／石牆守衛（防守型）
- 上面四行是當初的草案。查證後有三棟建築換了名稱、其中阿美的效果也換了，定案內容與原因見「階段 5 的內容」，**等使用者確認**。
- 平衡方法：用自動模擬對戰，讓任兩族的勝率落在 45% 到 55%。

**C. 族群關係（交流度與敵對度）**
- 每兩個族群之間有一個關係值，起始一律中立，不預設歷史恩怨。
- 交易、送禮、同聯盟會上升；出征對方族群的部落會下降。由全體玩家的行為共同累積，會慢慢回到中立。
- 友好：兩族之間交易有加成。敵對：兩族之間不能在市集直接交易，出征對方的戰功有加成。

**D. 野地資源點與中立聚落**
- 每個野地格有一種資源點（獵場、漁場、林地）。派勇士佔領後持續產出，別的部落可以來搶，同一時間只有一個部落佔領；沒人佔領時由野獸守著。
- 平埔族群的中立聚落只有幾處，用來交換各族特產，不能打；之後若核定為可遊玩的族群再升級。

**E. 人數加成**
- 依遊戲內各族的部落數計算：人數最少的族產量加 15%，依比例遞減，人數最多的族沒有加成，每天重算一次。

**F. 掛機設定**
- 採集重點（平均、糧食、建材、特產）、自動補訓守軍、自動升級建築。
- 離線最多累積 8 小時，回來時顯示離線報告。

**G. 傳說英雄與祝福**
- 每族一位可操控的「傳說英雄」，取自該族神話裡的人物，由任務主線解鎖，是強力、有特殊能力的角色。
- 神靈不能操控，只以「祝福」出現：完成任務後得到一段時間的加成。
- 階段 5 定案：四族查證的結果都建議不要做成「向神靈或祖靈換加成」，所以遊戲裡的祝福做成「共聚」——全部落聚在一起共食、同心，之後一段時間產量增加；不呈現祭儀、不出現神靈。英雄除了排灣的巴里以外都沒有名字（傳說裡本來就沒有），以「一群人」的身分出現。

**H. 對戰的互動形式：三路佈陣加臨場指令**（已作廢：使用者試過之後不喜歡，改成自動對戰、單一戰場的山林亂戰，見「已確認：對戰改成自動」。下面保留原本的紀錄）
- 進攻方把隊伍分配到正門、山徑、溪谷三條路；防守方事先設定佈防。
- 開打後分三個階段，每階段雙方各下一個指令（衝鋒、掩護射擊、重整）或發動英雄能力。
- 防守方在線上可以即時應戰，不在線上就照掛機設定的守備方針。
- 攻破兩路算勝，戰利品依攻破的路數計算。一場約一分鐘。

**I. 後台（上帝視角）**
- 只有使用者能登入，密碼放在伺服器的設定裡，不寫進程式。
- 看：所有部落的清單與進度、全島地圖總覽、各族人數與平均繁榮度、任兩族之間的對戰勝率。
- 調：全域平衡參數（產量、成本、兵種數值、各族特長），不用重新上線就生效；個別部落的資源增減（測試或補償用）。
- 每一次調整都留下紀錄。
- 使用者說之後可能再增加項目，後台要做成容易擴充。

## 文化內容的原則

- 族語、祭儀與物產必須先查證再放進遊戲，並標明語別或地區，不要混用不同方言的詞。
- 目前四族的內容是靠搜尋引擎摘要查證的，沒有直接讀到原住民族委員會、族語線上辭典的完整頁面。**正式推出前要請族人與專家審閱。**
- 無法查證的建築（訓練場、瞭望台、圍籬）在說明裡標示為「遊戲設定」。

各族需要避開或小心處理的內容：

| 族 | 注意事項 |
|---|---|
| 共通 | 不呈現獵首、頭骨架、傷亡；神聖或有身分意義的物品不當戰利品或交易品；紋樣只用一般幾何形狀 |
| 布農 | Pasibutbut 是祈禱，演唱者有限制，不做成音效或小遊戲；多數族人不接受「八部合音」這個名稱。射耳祭祭場有禁忌，不把獵首遊戲化；射耳祭不屬於「與月亮的約定」的農事祭儀。小米倉與種粟屬於家族，傳統上設在屋內、外人不能進入。木刻畫曆出自卡、丹社群，不是全族共通。射日故事的結局是和月亮立下約定，不是打敗太陽：不寫「殺死太陽」、不強調射中眼睛、孩子用「變成蜥蜴」的說法；父子沒有名字（「達瓦勾昂」是蘭社群、受鄒族影響的版本，不用）。獵具有禁忌，不當器物。布農語沒有固定的「獵人」名詞（打獵 hanup、獵場 hanupan），不用 mamangan 當兵種名。 |
| 阿美 | Ilisin 是祭儀不是表演，日期與規範由各部落決定，不做成按鈕。海祭等有性別限制。巫師（sikawasay）是現存的信仰，不做成法術。聚會所各地稱呼不同（'adawang、talo'an、soraratan、sefi），選定一個地區後要一致。美崙山巨人的傳說阿美族與撒奇萊雅族都有，出處要並列；頭目的名字各版本不同，不取名；海神只在夢裡出現、不取名；省略吃嬰兒內臟、假扮家人等情節。Pazik 是撒奇萊雅族的地名與人名，不借用。陶器是女性專屬、有禁忌的工藝，不當器物。巴拉告（Palakaw）是馬太鞍部落的做法，要標明。瞭望臺的阿美語（pikacawan／pikecoran）拼法有出入，先不放。 |
| 泰雅 | 不把紋面做成外觀或獎勵。不把 utux、彩虹橋做成能力。「頭目」是日治時期的稱呼，領袖稱 mrhuw。織布與 gaga 有關，圖案用一般條紋，不用特定命名紋樣。貝珠衣、織布機不當戰利品，也不當器物（傳統上男性不能碰織布機）。太魯閣族與賽德克族是獨立的民族，內容不要混入；賽夏族的射日版本（父子、走 18 年）也不要混入。射日傳說沒有留下名字，是一群人的行動，不替他們取名；沿路種的作物以橘子最常見。祖靈祭不做成按鈕，只以共聚表現。望樓在歷史上設在頭骨架旁，不畫；望樓的泰雅語查不到（lapaw 是田裡的看守臺，不能借用）；賽德克族、太魯閣族也有望樓。瑞岩（Pinsbkan）是聖地且各群說法不同，只放在文化卡，不做成任務。 |
| 排灣 | 陶壺、琉璃珠、青銅刀是貴族的傳家寶，不當交易品或戰利品。百步蛇紋、人頭紋、太陽紋是頭目與貴族專屬，不當一般裝飾；百步蛇不能當成敵人或獵物。石板屋是北、中排灣的做法，南、東排灣用木板與茅草。百合花是拉瓦爾群的習俗，不是全排灣共通。巴里（palji）的故事採用平安的結局：不寫目光致死、不寫他被害的結局、不指明來犯的是誰。**巴里是四族裡最需要請族人確認的英雄**：有部落避諱用「巴里」當人名，ma pu palji 在部分方言有負面意思，也有版本說他出自特定的貴族家。Masalut 不叫豐年祭，不呈現祭儀；五年祭（Maljeveq）與巫師（pulingaw）不放進玩法。芋頭窯的排灣語有 leku、lje'u 兩種寫法，先不放。不用 rakac、cakar、「士族」當兵種名；Tokanivon、Pulidjan 是家名，不當角色名。 |
| 魯凱 | 百合花、百步蛇、頭目家屋的木雕、百步蛇紋、陶壺、雲豹皮、老鷹羽毛都不畫、不當獎勵；雲豹只畫成傳說英雄「帶雲豹的始祖」身邊的動物（自然的走路或坐姿），不畫雲豹皮、不當獵物或獎勵，獨特建築和故事插圖不畫雲豹；和排灣是不同的民族，內容不混用。詳見「已加入：魯凱族、卑南族」。 |
| 卑南 | 祖靈屋、小米靈屋、護符、花環、人形舞蹈紋都不畫；巫師、會所、猴祭、大獵祭不做成玩法；lrayuan 不當「謝謝」。詳見「已加入：魯凱族、卑南族」。 |
| 雅美（達悟） | 文化上沒有出征的傳統，設計玩法時要留意。飛魚有嚴格的禁忌。 |

## 目前的進度

- **階段 1（部落經營）：使用者已確認。** 部落畫面依使用者要求改成斜上方俯視的立體場景，並加入拓荒。

階段 3 的內容：
- 開放訓練場（訓練勇士、弓手）、瞭望台、圍籬（畫成繞著開墾地的一圈）。「軍事」分頁可以訓練、升級圍籬、設定佈防、看戰報。
- **（對戰的部分已改成自動對戰，下面幾行是當時的做法，見「已確認：對戰改成自動」）**
- 佈防：重點守哪一路（平均、正門、山徑、溪谷；選一路就放一半守軍在那裡），以及不在線上時三個階段各下什麼指令。
- 出征：在地圖上點別人的部落 → 出征 → 決定派多少人、主攻哪一路。隊伍要走一段路（地圖上看得到移動的點），對方會收到「有隊伍正朝你而來」的警告。一次只能派一支隊伍。
- 對戰：三路同時打，共三個階段，每階段雙方各下一個指令。衝鋒剋重整、重整剋掩護射擊、掩護射擊剋衝鋒。守方在線上可以當場下令，不在或時間到就照預設；攻方時間到沒下令就衝鋒。攻破一路的人會轉去支援守軍最少的另一路。
- 對戰畫面（使用者要求要有畫面，不能只有數字）：三條路各畫一段戰場，攻方在左、守方在右，勇士拿矛、弓手拿弓，守方後面有圍籬、瞭望台和部落。使用者要求動作更多、背景更豐富，已加強。背景：依守方族群畫遠山或海面、山林、路邊草石、流動的溪水、部落裡的中心建築、家屋、小米田、冒煙的營火、飄動的旗子、雲影與飛鳥。動作：開打前走進場、雙方頭上跳出喊的指令（剋住對方的一邊是金色）、衝鋒揚塵與交鋒的碰撞、拉弓射箭與箭落地、被打到會晃動、重整蹲守、瞭望台射箭、失去戰力的人往自己那一邊退場（不畫倒下）、攻破時門柱倒下且攻方衝進部落並插旗、打完贏的一方歡呼。繪圖在 `public/art.js` 的 `battle()`，動作是 `public/style.css` 裡的動畫。
- 結果：攻破兩路算勝。攻破 1、2、3 路分別帶走對方可被拿走物資的 10%、25%、40%（每位回程的人背 30 份，先帶特產）。倉庫保護量內的物資拿不走。被攻破的一方得到保護時間。失去戰力的人寫成「負傷撤退」。
- 保護：新部落 10 分鐘、被攻破後 5 分鐘；主動出征會放棄保護；不能出征同盟、規模小太多的玩家、剛交手過的對象。
- 掛機：加上「離線時自動補訓守軍」。
- 後台：加上進行中的對戰數，以及各族對戰的場數與進攻方勝率。
- 示範部落只防守、不會主動出征。

階段 4 的內容：

- **後台**（`/admin`）分成四頁：
  - 總覽：原本的內容，部落清單多了「調整」，可以幫某個部落加減糧食、建材、任何一族的特產（不會超過倉庫容量），或給一段保護時間、取消保護。
  - 數值調整：節奏一鍵切換（快速 1、加速測試 5、正式 20，要按兩次才生效），其餘數值分組列出；改過還沒套用的欄位是金色，可以「套用修改」「放棄修改」「先用模擬試算」「全部還原成預設（節奏不變）」。
  - 模擬對戰：見下一點。可以設定每組幾場、雙方的隊伍、圍籬與瞭望台、有沒有英雄與獨特建築，也可以把還沒套用的修改算進去。計算在瀏覽器裡進行，不佔伺服器。
  - 操作紀錄：改數值、調整部落都會記下來（存檔保留最近 80 筆）。
- **後台的寫入**：`POST /admin/api/tune`（`{ set: {…} }` 或 `{ reset: true }`）、`POST /admin/api/adjust`。都要帶後台密碼、內容要是 JSON、最多 8 KB、數值會夾在允許的範圍內。密碼連續打錯 20 次會先擋 5 分鐘。玩家的連線沒有任何對應的動作。
- **自動模擬對戰**：實際對戰和模擬用同一份核心程式（`makeField`、`playPhase`、`fieldOver`、`fieldResult`）。雙方人數相同、佈陣重點隨機、每個階段的指令隨機，英雄各用一次（「世代接力」留到第二、三階段）。「兩族之間的整體勝率」＝甲進攻乙的勝率，加上乙進攻時甲守住的機率，除以二；目標是 45%～55%。`npm run sim` 會列出四種情境的報表，測試裡也有一項會檢查標準情境沒有超出範圍。
- **校正的結果**（每組 5000 場，數字是前者的整體勝率）：

| 情境 | 泰雅對布農 | 泰雅對阿美 | 泰雅對排灣 | 布農對阿美 | 布農對排灣 | 阿美對排灣 | 最大偏差 |
|---|---|---|---|---|---|---|---|
| 標準：勇士 4、弓手 4、獨特兵種 4，圍籬 1 級 | 47.7% | 51.4% | 52.6% | 51.2% | 48.4% | 47.3% | 2.7% |
| 沒有獨特兵種：勇士 6、弓手 6 | 49.8% | 50.3% | 48.5% | 51.1% | 47.5% | 47.9% | 2.5% |
| 獨特兵種為主：勇士 2、弓手 2、獨特兵種 8 | 52.4% | 47.9% | 50.3% | 47.7% | 49.6% | 51.2% | 2.4% |
| 大隊：各 6 人，圍籬 2 級、瞭望台 1 座 | 49.2% | 51.4% | 50.5% | 52.0% | 50.0% | 47.9% | 2.1% |

  校正前，標準情境的最大偏差是 11%（泰雅偏弱、排灣偏強）。各族仍然有攻守的特色：標準情境下，布農進攻成功約 67%、防守成功約 33%；泰雅 46%／54%；排灣 45%／56%；阿美 52%／47%。
- **為了平衡改了什麼**：
  1. 英雄能力不剋制對方、也不被對方剋制。原本英雄能力會被當成衝鋒、掩護射擊或重整其中一種，剛好形成固定的相剋圈（布農剋阿美、阿美剋泰雅與排灣、它們又剋布農），這是不平衡最大的來源。
  2. 泰雅的「世代接力」：負傷的人從全部歸隊改成一半歸隊（無條件進位），這個階段的攻擊折扣從六折改成七折。全部歸隊在人多、工事高的時候太強。
  3. 山林獵手守部落的攻擊加成 30% → 20%；部落青年的同伴加成每人 3% → 2%；石牆守衛守部落的耐力加成 30% → 10%，攻擊 8 → 9、耐力 34 → 32；獵人耐力 18 → 19；部落青年耐力 28 → 29；望樓的守軍加成 12% → 11%。
  4. 戰況文字裡「誰剋住誰」原本是用承受的倍率比大小，重整永遠看起來像剋住別人；改成照真正的相剋關係判斷。
- **這套平衡沒有涵蓋的**：
  - 石板豬圈、巴拉告、芋頭窯是經濟上的效果，對戰模擬量不到，三者之間、以及和望樓相比划不划算，還沒有校正。
  - 模擬用的是隨機指令，代表「一般情況」，不代表高手之間的對決。
  - 只帶勇士和弓手、弓手特別多、又有工事的情境，泰雅對阿美約 55%，略超出範圍。
- **順便修掉的漏洞**（階段 3 就存在）：玩家如果把出征目標、指令、兵種、聯盟編號等寫成 `__proto__`、`constructor`、`toString` 這類名稱，規則會出錯，伺服器沒有攔截就會整個停掉，任何連上線的人都做得到。現在所有查表用的物件都改成沒有原型的字典（`dict()`），伺服器每個事件處理也包了一層攔截（出錯只記錄，不會停機），並加了一項測試。**之後新增「用玩家送來的名稱查表」的地方，表要用 `dict()` 建立。**

單機試玩的測試工具（使用者要求）：「測試」分頁可以開無限資源、讓工程和訓練立刻完成、戰士補滿、出征的隊伍立刻抵達，也可以重新開始。階段 5 加上「任務這一章直接完成」「英雄和共聚不用等」。階段 6 加上「遊戲節奏」的切換（快速試玩／正式節奏），可以在預覽頁體驗正式節奏的快慢。這些只寫在 `public/net.js` 的單機模式裡，連線版沒有對應的動作，伺服器不會接受。

公開測試要注意：更新到這一版之後，連線版會變成正式節奏（比之前慢二十倍）。如果朋友正在用舊的快節奏測試、想維持原狀，到後台的「數值調整」把節奏切回「快速試玩」就可以。

階段 7 的內容：
- **流量改善**（之前擱置的項目）：伺服器只傳有變動的部分。
  - 全島的部落清單每秒只算一次，和上一秒比對；每個連線只收有變動的部落（`vd`）和被移除的部落（`vx`），第一次連上才拿完整清單。
  - 自己的部落只送有變動的欄位（`mp`）；消息只送新的（`feedAdd`）；關係、資源點、市集、聯盟、對戰沒有變就不送。`public/net.js` 負責把這些合併回完整的狀態再交給畫面。
  - 超過 1 KB 的訊息才壓縮；網頁的程式檔用 gzip 壓縮，瀏覽器手上的版本沒變就不重傳。
  - 實測（正式節奏、280 人同時在線）：每人每秒從約 69 KB 降到約 0.1 KB，伺服器每秒總共送出約 27 KB，CPU 約 6%，記憶體約 150 MB。快速節奏下變動多，流量會高很多（每人每秒約 5 KB），那不是正式環境的設定。
- **換裝置（部落代碼）**：部落的鑰匙是一組存在瀏覽器裡的識別碼，現在改用安全的亂數產生（`p` 加 24 個字）。「部落」分頁最下面可以顯示代碼、複製連結；開始畫面最上面可以輸入代碼接回部落；打開帶著 `#t=代碼` 的連結也會接回（用完就從網址上拿掉）。同一個部落可以同時在好幾臺裝置上開著。伺服器不收少於 16 個字的識別碼。單機試玩沒有這個功能。
- **公開後的防護**：
  - 同一個網路位置最多 20 個連線、每小時最多建立 5 個新部落；全部連線上限 2000；玩家部落上限 300（都可以用環境變數調整）。在 Railway 上，來源位置用 `X-Real-IP`（Railway 會覆蓋玩家自己塞的標頭）。
  - 瀏覽器的安全設定：網頁只執行自己網站上的程式檔（所以後台的程式移到 `public/admin.js`）、不能被別的網站嵌入、不猜檔案類型、不外洩來源網址。
  - 伺服器每個事件處理都有攔截，出錯只記錄、不停機（階段 6 加的）。
- **存檔保險**：每 6 小時多留一份備份，保留最新 8 份，放在存檔旁邊的 `backups` 資料夾；啟動時如果存檔讀不出來，會把壞掉的檔案改名留著，再自動改用最新的備份。後台可以下載存檔、馬上備份一次。
- **後台的管理功能**：「調整」視窗多了改名（部落名稱、主人的名字）與移除部落（要按兩次）。移除時，它派出去的隊伍、佔領的資源點、掛的單、聯盟身分一併清掉，別人朝它出征的隊伍折返，識別碼作廢，還在線上的玩家會回到開始畫面；交戰中不能移除。總覽多了「伺服器」一格：運作多久、記憶體、連線數、每秒送出的流量、上次存檔、備份數。
- **遊戲裡的說明**：開始畫面和圖鑑最下面有「關於這個遊戲」，寫明文化內容的來源、**還沒有經過族人審閱**、不呈現獵首與傷亡、只記名字與進度。伺服器設定 `CONTACT_TEXT` 的話，最後會多一句聯絡方式。
- **上線步驟**寫在 README：第一次部署、健康檢查路徑、用自己的網址（要加 CNAME 和 TXT 兩筆設定）、上線前的檢查表、上線之後的維護。Railway 的設定檔（railway.json）已經被 Railway 淘汰，所以沒有放，健康檢查路徑要在 Railway 的設定頁填。

之後要加一個族群時的做法：
1. 先查證（族語、建築、物產、神話、禁忌），整理出該族「需要避開或小心處理的內容」寫進上面的表格。
2. 在 `shared/tribes.js` 把該族補齊（`playable: true`、建築名稱與說明、物產、族語、文化卡、`uniq`、`hero`、`bless`、`items`、`story`、`quests`）。地圖上的分布區在 `shared/geo.js` 已經有了。
3. 在 `public/art.js` 補上該族的獨特建築畫法（`ISO.unique`），需要的話補中心建築、特產建築的樣子。
4. 新的效果、特性、英雄能力要在 `shared/world.js` 加上規則，並在 `public/client.js` 加說明文字。可調的數值加進 `TUNE_DEF`。
5. 跑 `npm test` 與 `npm run sim`，確認新的一族和原有各族之間都在 45%～55%。
6. 雅美（達悟）族要另外做海路的規則，而且文化上沒有出征的傳統，動工前要先和使用者討論。

還沒做、之後可以考慮的：
- 後台還沒有：發公告、手動選一份備份還原、把數值匯出或匯入、封鎖某個來源。
- 棄置的部落不會自動回收。玩家部落的上限是 300，長期營運需要決定「多久沒上線、規模多小」的部落可以回收；這會刪掉玩家的資料，要先和使用者討論。
- 流量還可以再省：自己的糧食與建材現在每秒傳一次，可以改成讓瀏覽器自己推算。
- 經濟型獨特建築（石板豬圈、巴拉告、芋頭窯）之間的平衡，以及正式節奏的實測（見「階段 6 的內容」）。
- 英雄有等級（1～5）和英雄卡，但沒有獨立的半身肖像（目前放大英雄的全身圖）。
- 文化內容請族人與專家審閱（四族都還沒有）；畫師的美術素材。

## 和《萬國覺醒》的比較（使用者問的，還沒有決定要不要補）

使用者拿《萬國覺醒》（大型的手機策略遊戲）來問「差在哪」。兩款是同一類（蓋基地、練兵、結盟、打別人），主要的差別：

- 我們比它少的：長期目標（活動、賽季、排行榜）、聯盟的共同目標（領土、集結）、電腦敵人（一個人也有東西可打）、地圖上自由行軍的臨場感、養成的層次（兵種階級、科技、統帥培養）。
- 我們刻意不一樣的：不抽卡不賣加速、各族用模擬對戰校正到勢均力敵、對戰要當場下指令、文化內容是主角且有底線、打開網址就能玩。
- 建議（都算新的方向，要使用者確認才做）：一、排行榜加上定期的賽季目標；二、聯盟的共同目標；三、一個人也能打的對象（例如山豬群、颱風過後的搶修，不設定成敵對的族群）。不建議去追它的規模。

## 待確認的新方向：把部落養成加深（使用者問「能不能改成萬國覺醒那樣的部落養成」）

**還沒有動工，等使用者決定範圍。** 做的是同一類型的養成結構，內容（建築、名稱、數值）都用山海部落自己的，不照抄那款遊戲。

那款遊戲的養成有哪幾塊、我們現在的狀況、建議的做法：

| 養成的部分 | 我們現在 | 建議改成 |
|---|---|---|
| 中心等級 | 5 級，只限制其他建築的等級上限 | 拉長（建議 15 級），每一級要先把指定的建築升到某一級 |
| 建築種類 | 10 種 | 增加療養屋、學習技藝的地方等 |
| 研究 | 沒有 | 「技藝」：生產類與守備類，花時間學會後永久加成 |
| 兵種階級 | 每種兵只有一階 | 三階，靠訓練場等級與技藝解鎖 |
| 負傷的人 | 負傷撤退就不見了 | 進療養屋慢慢康復、歸隊（很合我們「不呈現傷亡」的原則） |
| 英雄養成 | 只有一個能力，不能成長 | 先不做，或做得很輕；英雄是神話人物，「練等」在文化上要小心 |
| 戰力 | 沒有 | 一個總分數，可以做排行榜 |
| 引導任務 | 只有五章神話任務 | 另外加「部落發展任務」，一路帶著玩家升級 |
| 外觀隨發展改變 | 沒有 | 可選，需要美術配合 |
| 加速、VIP、課金 | 沒有 | 不做課金；加速道具可以當任務獎勵（待使用者決定） |

建議分三批：第一批是骨架（中心等級拉長與前置條件、戰力、部落發展任務、舊存檔換算）；第二批是技藝與療養屋；第三批是兵種階級、排行榜、外觀隨發展改變。

代價：平衡要重新模擬；我們不賣加速，等待時間不能照那款遊戲那麼長，不然只剩等待；現有玩家的部落要換算等級；建築外觀要不要隨等級變要另外請美術；新的名稱要查證或標成遊戲設定。

要請使用者決定：一、做全部三批，還是先做第一批；二、中心等級拉到多長（10、15 或 25）；三、要不要有不收費的加速道具。

使用者接著問「或是參考王國紀元呢」。兩款的養成骨架幾乎一樣（中心等級、建築前置、研究、兵種階級、醫療、戰力），差在骨架外面那一圈。王國紀元有幾樣比較適合我們，可以另外挑：
- 聯盟互助：盟友按一下，幫你縮短一點工程時間。
- 定時任務：隔一段時間可以領一次的小任務，適合掛機。
- 野外的對象：一個人也有東西可打（我們改成山豬群、災後搶修這類，不設定成敵對的族群）。
- 故事關卡：把神話任務做成一關一關。
- 兵種相剋與陣型：和我們的三條路、指令相剋接得上。
**不能借的**：俘虜對方領主與處決（牴觸「不呈現獵首與傷亡」）、抽英雄與收集幾十位英雄（我們的英雄是神話人物）、課金加速與 VIP。
第四題要請使用者決定：外面那一圈要哪幾樣。

魯凱族（Drekay）：

  - 蓋好或升級 1 次建築

- 升一級要：糧食、建材、自己族群的特產，再花一段時間（和蓋建築一樣用倒數；可以用加速）。等級越高花越多，也要部落中心到一定等級（2 級要中心 6 級、3 級要 9 級、4 級要 12 級、5 級要 15 級）。
- 效果（**和提案不同，做的時候改的**）：原本提案是「每升一級，英雄能力本身多兩成」。實際模擬後發現各英雄的能力之間有相剋（例如阿美的「齊心」第一次交鋒減少損失，剛好擋掉魯凱「雲豹的山徑」第一次交鋒的攻擊；排灣的「守望」怎麼加都幾乎沒有差別），兩邊都升到 5 級時各族會差到兩成以上，各自調整幅度也調不平。所以改成：**英雄在場時，全隊的攻擊與耐力每級多 3%**（5 級是 +12%，後台可以調 `heroLvAll`），**能力本身的數字不變**；**用過之後要休息的時間每級少一成**。這樣各族一樣，同族 5 級打 1 級大約七成會贏。
- 平衡：`npm run sim` 多一種情境「英雄都是 5 級」，和其他 6 種情境一樣六族兩兩都在 45%～55% 之內。
- 花費：糧食、建材各「300 × 那一級要求的中心等級倍率」（2 級約 1,875、3 級約 3,660、4 級約 7,150、5 級約 13,970），特產 70／100／130／160；時間（正式節奏）2 級 1 小時、3 級 2 小時、4 級 4 小時、5 級 8 小時，可以用加速。升完加季分（20 × 等級）。

### 賽夏族（SaySiyat）
- 分布：新竹五峰（北賽夏，大隘群）、苗栗南庄、獅潭（南賽夏，東河群），夾在泰雅族與客家人之間，北群多會說泰雅語、南群多會說客家語。
- 家屋：長方形，粗竹或原木當柱子，竹子編牆，屋頂鋪竹片或茅草；竹屋冬暖夏涼，但竹子會受潮腐爛，幾年要重蓋一次。屋裡放藤編的穀倉籠和杵臼。
- 生活：山田燒墾、狩獵，小米是主要作物；婦女種苧麻織布。**編籃工藝在各族中最具特色**：用桂竹、黃籐編背籃、米篩、種子籃、提籃、籐帽；背籃是雙肩帶的（泰雅族是額帶式），傳統的是喇叭型。
- 姓氏：取自大自然的動植物或現象，清代改漢姓時取相近的意思或音，例如日、風、樟、蟹（夏）、豆、絲、芎。
- 傳說：洪水時，祖先在大霸尖山（只剩一對夫妻）；子孫往南走到 tamari'（據說在阿里山附近），再沿著海邊到竹南、後龍一帶，然後往山裡走（竹東、北埔都住過），最後住在五峰、南庄。各地說法不同（西南部的說法是加里山）。**另一個版本有殺害嬰兒的情節，不用。**
- 小心：paSta'ay（矮靈祭）是最重要、最神聖的祭儀，**不做成玩法、不畫**；矮人（ta'ay）的傳說有傷亡情節，不用；肩旗（kilakil）、臀鈴、蛇鞭、放祖靈象徵物的小籐籃都是祭儀用的，不畫、不當道具或獎勵；紋面不用；織紋裡的菱形紋、雷女紋（雷女傳說的紋樣）是賽夏族的紋樣，照原則只用一般幾何紋；火神祭（敵首祭）不用。大霸尖山也是泰雅族的祖山，故事只寫賽夏族的說法，不寫成哪一族專屬。
- 族語：族語E樂園九階教材第一課是「So'o kayzaeh ay?」（你好嗎？）。「謝謝」只在維基教科書和網友留言看到 ma'alo'，不夠可靠，先不放。

### 鄒族（Cou）
- 分布：嘉義阿里山鄉（達邦、特富野兩個大社，北四村、南三村），也有因莫拉克風災遷到番路鄉的部落。卡那卡那富族、拉阿魯哇族 2014 年起是獨立的族，不混在一起。
- 社會：大社（hosa）下有小社；氏族；幾個家族組成的聯合家族共有耕地和**河流漁區**（例如某段溪流上游屬於某一家）。
- 家屋：以日出、日落為軸的**橢圓形**平面，屋頂是像天幕一樣的**茅草**木構架；牆用竹子或較硬的茅草；屋裡有火塘、竹床、穀倉。前門向東、後門向西。
- 生活：農耕、狩獵、漁撈照四季進行，小米最重要（從播種到入倉都有祭儀）。**鞣皮**：用山羌、山羊或鹿的皮做皮衣、皮褲，現在會的人很少。
- 傳說：神 Hamo 搖動楓樹，落下的葉子變成鄒族的祖先（神只在故事裡出現，不能操控）。**大洪水**：一條巨大的鰻魚橫在溪裡擋住水，洪水淹上來，族人逃到玉山（patungkuonu）山頂避難；後來一隻螃蟹把鰻魚趕走（剪斷或夾住牠），水退了，族人下山，沿著楠梓仙溪、曾文溪、阿里山溪、陳有蘭溪建立部落。**螃蟹要的報酬在各版本有成人的情節，不寫；取火的段落各版本差很多、也有獵首歌謠的段落，都不用。**
- 小心：kuba（男子會所）只有該部落的男性能進，**不畫、不做玩法**；mayasvi（戰祭）、homeyaya（小米收穫祭）是祭儀，不做成玩法；獸骨架（hufu，放獸骨、武器和禁忌的東西，女性不能靠近）、小米祭屋不畫；帽子上的鷹羽（要親自射下猛禽才能戴）不畫、不當獎勵；皮衣上塗獵物的血代表戰功，不畫；patungkuonu 這個名字的由來和出草有關，遊戲只寫「玉山」與族語名，不解釋由來。

  - 療養、英雄升級：要肉。
  - 技藝、拓荒、共聚：照用途分配（例如拓荒要木頭、共聚要米和肉）。
- **部落裡原本的「建材採集場」**：木頭和石頭不能在部落裡生產了，改成「採集隊的營地」，每升一級讓採集隊伍背得多一點、走得快一點。舊存檔裡的採集場自動變成營地，等級不變。
- **族人的分工**：剩下種田、做特產，以及**組採集隊出去採**（派出去的族人不在部落裡工作）。
- **剛開始怎麼拿到木頭、石頭**：新部落送一些木頭和石頭；部落附近一定有幾個低等級的林地、岩場；**族人也可以組採集隊**（不用先有戰士）。族人採集隊遇到有人來搶不會打，會丟下一部分東西跑回來；有戰士同行才會抵抗。
- **掛機**：可以設定「離線時自動派族人去附近採集」，不然離線時木頭、石頭都不會增加。
- **倉庫**：四種資源各有自己的容量和受保護的量。
- **交易、送禮、掠奪、任務獎勵、每日任務、請託、賽季、聯盟目標**：全部改成這四種資源，獎勵照用途分配。
- **舊存檔**：原本的「糧食」變成米；原本的「建材」照族群拆成木頭和石頭（石板屋族群石頭多、其他木頭多）；肉從 0 開始，另外補一些讓大家不會卡住。
- **畫面**：上方的資源列變成米、木頭、石頭、肉、特產；需要木頭、石頭、肉的圖示（現有的 icon-material、icon-meat 可以先用，之後再請美術補）。
- **平衡**：建設的節奏會變慢（要出門採），會用自動試玩把花費和採集量調到和現在差不多的節奏。對戰本身不受影響。

### 要請使用者決定
1. 「米」是叫「小米」還是「米」：多數族群傳統的主食是小米，阿美族後來才改種水稻。建議叫「小米」。
2. 肉的用途：建議用在訓練、療養、英雄升級，戰士不用每天吃肉（避免肉不夠時戰士一直餓）。
3. 剛開始怎麼拿到木頭、石頭：建議族人也能組採集隊，加上開局送一些、附近一定有資源點。
4. 布農族的特產「山肉」、阿美族的「漁獲」會和新的「肉」重疊：建議把這兩族的特產換成別的（先查證再提給使用者），或是保留不變。
