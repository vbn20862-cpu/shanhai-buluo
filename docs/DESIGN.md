# 山海部落：設計方向

> 狀態：**方向已全部確認，依製作計畫分階段製作中**（目前：階段 1）。
> 每個階段做完先給使用者看預覽，確認後才做下一階段。有新的方向要先討論、記進這份文件，再動工。

「山海部落」是暫定名稱。使用者以繁體中文（臺灣用語）溝通，說明要白話、少用技術詞。

## 已確定的方向

| 項目 | 決定 |
|---|---|
| 主題 | 臺灣原住民族，文化推廣與一般大眾娛樂並重 |
| 類型 | 選單式部落經營模擬（採集、建設、訓練），參考部落衝突與世紀帝國的採集建設；不做開放世界 |
| 平臺 | 橫式手機網頁，之後再評估包成 App 上架 |
| 連線 | 多人即時連線，伺服器當唯一裁判 |
| 地圖 | 臺灣全島，自然風格（平滑海岸線、區域是邊界柔和的色塊）；六角格只藏在背後當預設落腳點，一格可以有多個部落 |
| 時空 | 只有原住民族的南島時期，不放閩漢 |
| 衝突 | 部落之間可以出征、搶奪資源 |
| 族群 | 以官方認定的 17 族為準（2026 年 7 月核定西拉雅族為第 17 族），各族要平衡、彼此要有關係，一族一族慢慢開發 |
| 掛機 | 離線前可以設定採集哪些資源等，離線期間照設定累積 |
| 第二款 | 神話故事冒險另外開發，不併進這一款 |
| 製作環境 | 專案放在 GitHub（本專案庫），可以在 MacBook 上用 Claude 桌面版製作，也可以用雲端對話 |
| 時代呈現 | 架空的古代（「很久以前」），不對應特定年代 |
| 沒有族群的格子 | 混合：大部分是無主野地（有獵場、漁場等資源點，可以爭奪），少數是平埔族群的中立聚落（可交易、不能玩也不能打） |
| 誰跟誰打 | 以玩家的部落為單位，同族也能互打，聯盟可以跨族 |
| 族群之間的關係 | 有正向的交流度，也有敵對度 |
| 衝突的程度 | 出征搶物資，加上爭奪野地資源點；部落本身不會被打掉或佔領，只損失物資和一段時間 |
| 平衡方式 | 每族有獨特的兵種或建築（不是全族相同），但整體強度要相當 |
| 領域大小落差 | 強弱不跟領域大小掛鉤；小區域每格容納更多部落、可使用鄰近野地；依照人數，人越少的族群加成越多 |
| 雅美（達悟） | 規則和其他族完全一樣，只是進出蘭嶼都走海路、時間較長 |
| 離線時 | 可以被出征，但有倉庫保護量與戰敗後的保護時間 |
| 長期目標 | 永久世界加排行榜（繁榮度、戰功、聯盟） |
| 第一版開放的族群 | 泰雅、布農、阿美、排灣，其餘陸續加入 |
| 美術風格 | 先用程式畫的扁平向量插畫，素材要做成可以替換，之後換成畫師作品 |
| 紋樣 | 素材做成可替換；開發階段用一般幾何圖形，取得該族或部落授權後才換上專屬紋樣，並且只放在身分正確的地方 |
| 戰利品 | 用珍貴但不神聖的東西（各族特產與工藝品）；神聖物品不當戰利品 |
| 獵首與傷亡 | 先保留「不呈現」；戰敗寫成「撤退」 |
| 任務系統 | 每族有以神話故事為基底的任務，完成後解鎖新物品或新兵種 |
| 部落畫面 | 不用方格。從斜上方俯視的立體場景，像世紀帝國、三國志；建築蓋在融入風景的固定建地上；場景比螢幕大，可以拖曳縮放；操作仍是選單式 |
| 拓荒 | 部落的開發需要拓荒：一開始只有中央一小塊開墾地，外圍是山林，要派人拓荒才有新的建地 |

## 已確認的細節

使用者已確認下面 A 到 F。例外是 A 裡「神靈能不能操控」和新增的兩項，見後面的「待確認」。

**A. 任務系統**
- 每族一條主線，共 5 章，取材自該族的一則神話。每章是一小段故事、一個用經營玩法完成的目標、一份獎勵。
- 目標類型：累積物資、蓋或升級建築、訓練、佔領野地資源點、和別族交易、出征。
- 獎勵：前幾章給物資與「器物」（永久小加成的工具），第 3 章解鎖獨特建築，第 5 章解鎖獨特兵種。各族章數與獎勵強度相同。
- 故事只用公開流傳的版本並標明出處；文字要請族人審閱。
- 候選神話（都還要查證）：布農「射日與月亮的約定」、泰雅「射日」、阿美「巨人 Alikakay」、排灣待定。

**B. 各族獨特建築與兵種**（使用者認可這份草案；文化依據要再查證）
- 所有族共用勇士、弓手兩種基本兵種，每族另有一棟獨特建築與一種獨特兵種。
- 泰雅：望樓（提早發現來襲、防守加成）／山林獵手（防守時較強）
- 布農：獵寮（野地資源點採集加成）／獵人（強化的弓手）
- 阿美：聚會所的年齡階級（訓練較快）／青年階級（同行人數越多越強）
- 排灣：石板建築（建築耐打、倉庫保護量較高）／石牆守衛（防守型）
- 平衡方法：用自動模擬對戰，讓任兩族的勝率落在 45% 到 55%。

**C. 族群關係（交流度與敵對度）**
- 每兩個族群之間有一個關係值，起始一律中立，不預設歷史恩怨。
- 交易、送禮、同聯盟會上升；出征對方族群的部落會下降。由全體玩家的行為共同累積，會慢慢回到中立。
- 友好：兩族之間交易有加成。敵對：兩族之間不能在市集直接交易，出征對方的戰功有加成。

**D. 野地資源點與中立聚落**
- 每個野地格有一種資源點（獵場、漁場、林地）。派勇士佔領後持續產出，別的部落可以來搶，同一時間只有一個部落佔領；沒人佔領時由野獸守著。
- 平埔族群的中立聚落只有幾處，用來交換各族特產，不能打；之後若核定為可遊玩的族群再升級。

**E. 人數加成**
- 依遊戲內各族的部落數計算：人數最少的族產量加 15%，依比例遞減，人數最多的族沒有加成，每天重算一次。

**F. 掛機設定**
- 採集重點（平均、糧食、建材、特產）、自動補訓守軍、自動升級建築。
- 離線最多累積 8 小時，回來時顯示離線報告。

**G. 傳說英雄與祝福**
- 每族一位可操控的「傳說英雄」，取自該族神話裡的人物，由任務主線解鎖，是強力、有特殊能力的角色。
- 神靈不能操控，只以「祝福」出現：完成任務後得到一段時間的加成。

**H. 對戰的互動形式：三路佈陣加臨場指令**
- 進攻方把隊伍分配到正門、山徑、溪谷三條路；防守方事先設定佈防。
- 開打後分三個階段，每階段雙方各下一個指令（衝鋒、掩護射擊、重整）或發動英雄能力。
- 防守方在線上可以即時應戰，不在線上就照掛機設定的守備方針。
- 攻破兩路算勝，戰利品依攻破的路數計算。一場約一分鐘。

**I. 後台（上帝視角）**
- 只有使用者能登入，密碼放在伺服器的設定裡，不寫進程式。
- 看：所有部落的清單與進度、全島地圖總覽、各族人數與平均繁榮度、任兩族之間的對戰勝率。
- 調：全域平衡參數（產量、成本、兵種數值、各族特長），不用重新上線就生效；個別部落的資源增減（測試或補償用）。
- 每一次調整都留下紀錄。
- 使用者說之後可能再增加項目，後台要做成容易擴充。

## 文化內容的原則

- 族語、祭儀與物產必須先查證再放進遊戲，並標明語別或地區，不要混用不同方言的詞。
- 目前四族的內容是靠搜尋引擎摘要查證的，沒有直接讀到原住民族委員會、族語線上辭典的完整頁面。**正式推出前要請族人與專家審閱。**
- 無法查證的建築（訓練場、瞭望台、圍籬）在說明裡標示為「遊戲設定」。

各族需要避開或小心處理的內容：

| 族 | 注意事項 |
|---|---|
| 共通 | 不呈現獵首、頭骨架、傷亡；神聖或有身分意義的物品不當戰利品或交易品；紋樣只用一般幾何形狀 |
| 布農 | Pasibutbut 是祈禱，演唱者有限制，不做成音效或小遊戲；多數族人不接受「八部合音」這個名稱。射耳祭祭場有禁忌，不把獵首遊戲化。小米倉與種粟屬於家族，傳統上設在屋內、外人不能進入。木刻畫曆出自卡、丹社群，不是全族共通。 |
| 阿美 | Ilisin 是祭儀不是表演，日期與規範由各部落決定。海祭等有性別限制。巫師（sikawasay）是現存的信仰，不做成法術。聚會所各地稱呼不同（'adawang、talo'an、soraratan、sefi），選定一個地區後要一致。 |
| 泰雅 | 不把紋面做成外觀或獎勵。不把 utux、彩虹橋做成能力。「頭目」是日治時期的稱呼，領袖稱 mrhuw。織布與 gaga 有關，圖案用一般條紋，不用特定命名紋樣。貝珠衣、織布機不當戰利品。太魯閣族與賽德克族是獨立的民族，內容不要混入。 |
| 排灣 | 陶壺、琉璃珠、青銅刀是貴族的傳家寶，不當交易品或戰利品。百步蛇紋、人頭紋、太陽紋是頭目與貴族專屬，不當一般裝飾；百步蛇不能當成敵人或獵物。石板屋是北、中排灣的做法，南、東排灣用木板與茅草。百合花是拉瓦爾群的習俗，不是全排灣共通。 |
| 雅美（達悟） | 文化上沒有出征的傳統，設計玩法時要留意。飛魚有嚴格的禁忌。 |

## 目前的進度

- **階段 1（部落經營）：使用者已確認。** 部落畫面依使用者要求改成斜上方俯視的立體場景，並加入拓荒。
- **階段 2（連線與掛機）：已做完，等使用者看過確認。** 確認後才做階段 3（對戰）。

階段 1 的內容：
- 自然風格的臺灣地圖（平滑海岸線、暈染的區域色塊、山脈），可拖曳縮放；格子藏在背後，一格可住 7 個部落。
- 沒有族群的格子分成野地（獵場、漁場、林地）與 5 處中立聚落，目前只顯示說明，玩法在階段 4。
- 選區域落腳、族人分工（可自動或手動）、蓋與升級建築、施工倒數。
- 部落畫面是斜上方俯視的立體場景：中央廣場加三圈共 29 塊建地，周圍是山林，山區有溪、海岸有沙灘與海；族人會在開墾地附近走動。
- 拓荒：只能從已開墾的地往外拓；花糧食與時間，清出來的木石變成建材；最外圈要部落中心等級 2。拓荒和蓋房共用 2 個工程名額。
- 泰雅、布農、阿美、排灣四族的建築外觀、名稱、特產、特長、族語與文化卡；圖鑑列出 17 族。

階段 2 的內容：
- 伺服器（`server.js`，用 socket.io）：所有玩家在同一個世界，伺服器當裁判，每 20 秒存檔到 `data/world.json`，重啟後進度還在。玩家用瀏覽器裡的識別碼回到自己的部落。
- 互訪：在地圖上點別人的部落可以進去參觀（只能看），每 3 秒更新。
- 掛機設定：採集重點（平均、糧食、建材、特產）與「離線時自動升級建築」。離線最多累積 8 小時。
- 離線報告：離開超過 1 分鐘，回來時顯示這段時間的收穫與升級。
- 後台（`/admin`，檢視）：密碼由啟動時的 `ADMIN_PASSWORD` 設定，沒設定就不開放。可看總覽數字、全島地圖、各族統計、所有部落清單（可排序）。
- 沒有伺服器時（例如預覽頁），遊戲會自動改成單機模式，同一套規則在瀏覽器裡跑。

公開測試（使用者要求提前做，讓不在身邊的朋友也能測）：
- 伺服器加了邀請碼（`JOIN_CODE`）、玩家人數上限（`MAX_VILLAGES`，預設 300）、健康檢查（`/healthz`）。
- 主機選 Railway（每月約 5 美元、一直開著、有硬碟保留存檔）。原本考慮的 Zeabur 已宣布 2026 年底停止營運，不能用。免費方案（Render 等）會休眠且存檔會消失，不適合。步驟寫在 README。
- 使用者是否已經完成部署、網址是什麼，要問使用者；這份文件不記密碼與邀請碼。

還沒做、留到後面階段的：
- 「自動補訓守軍」的掛機選項（階段 3 有兵種後加入）。
- 後台的調整功能與對戰勝率（階段 6）。
- 部落中心升到 3 級以上暫時用「自己的特產」；階段 4 有交易後改成「別族的特產」（`shared/world.js` 的 `FOREIGN_SP`）。
- 軍事建築、出征、市集、聯盟的規則已寫在規則核心裡，但畫面還沒開放。現有的對戰是自動結算，階段 3 要改成三路佈陣加臨場指令。
- 族人只是在開墾地附近走動，還沒有走去田裡或樹林工作的動畫。

## 程式結構

| 檔案 | 內容 |
|---|---|
| `shared/geo.js` | 臺灣輪廓、六角格、各族分布區、野地與中立聚落、山脈稜線 |

| `public/admin.html` | 後台頁面（檢視） |

| `test/world.test.js` | 規則核心的自動測試 |
