# 山海部落：設計方向

> 狀態：**方向確認中**。使用者明確要求「在確定所有方向前都不要製作，避免方向錯誤」。
> 下面「待確認」的題目全部有答案之前，不要寫遊戲程式或畫面，只做討論與整理。

「山海部落」是暫定名稱。使用者以繁體中文（臺灣用語）溝通，說明要白話、少用技術詞。

## 已確定的方向

| 項目 | 決定 |
|---|---|
| 主題 | 臺灣原住民族，文化推廣與一般大眾娛樂並重 |
| 類型 | 選單式部落經營模擬（採集、建設、訓練），參考部落衝突與世紀帝國的採集建設；不做開放世界 |
| 平臺 | 橫式手機網頁，之後再評估包成 App 上架 |

| 時空 | 只有原住民族的南島時期，不放閩漢 |

## 待確認的方向（附建議）

1. **時代怎麼呈現**：A 架空的古代（不對應特定年代）／B 對應特定史前時期。建議 A，因為 17 族的分類是現代才有的。
2. **沒有族群的格子**：A 無主野地，有獵場、漁場等資源點可以爭奪／B 平埔族群的中立聚落，可交易、不能玩也不能打／C 混合。建議 C。
3. **誰跟誰打**：A 以玩家的部落為單位，同族也能互打，聯盟可以跨族／B 以族群為陣營。建議 A，避免族群對立，也比較好平衡。
4. **族群之間的關係**：A 只累積正向的交流度（交易、送禮越多，加成越高）／B 另外有敵對度。建議 A。
5. **衝突做到什麼程度**：搶物資已確定。建議再加「爭奪野地資源點」；部落本身不會被打掉或佔領。
6. **平衡方式**：A 所有族的建築與兵種相同，只換名稱、外觀、族語，每族一項等值特長／B 每族有獨特兵種或建築。建議 A。
7. **領域大小落差**（泰雅 42 格；撒奇萊雅、雅美各 1 格）：建議強弱不跟領域大小掛鉤，小區域每格容納更多部落、可使用鄰近野地，人數少的族群給小幅加成。
8. **雅美（達悟）怎麼參與**：A 規則和其他族完全一樣，只是進出蘭嶼都走海路、時間較長／B 偏貿易漁撈、不主動出征。建議 A（符合平衡）；B 較貼近文化但玩法不對等。
9. **離線時**：A 可以被出征，但有倉庫保護量與戰敗後的保護時間／B 離線完全不會被打。建議 A。
10. **長期目標**：A 永久世界加排行榜（繁榮度、戰功、聯盟）／B 賽季制。建議 A。
11. **第一版開放的族群**：A 先開放泰雅、布農、阿美、排灣，其餘陸續加入／B 17 族同時開放但內容較淺。建議 A。
12. **美術風格**：A 扁平向量插畫，直接用程式畫，之後可換成畫師作品／B 像素風／C 其他。建議先用 A。
13. **敏感內容的處理**：不呈現獵首與傷亡，戰敗寫成「撤退」；神聖物品不當戰利品；不使用各族專屬紋樣。建議維持。

曾經討論但已放棄的方向：節奏指揮玩法（Patapon 式）、開放世界（世紀帝國式的自由移動）、把沒有族群的格子設為閩漢市鎮。

## 文化內容的原則

- 族語、祭儀與物產必須先查證再放進遊戲，並標明語別或地區，不要混用不同方言的詞。
- 目前四族的內容是靠搜尋引擎摘要查證的，沒有直接讀到原住民族委員會、族語線上辭典的完整頁面。**正式推出前要請族人與專家審閱。**
- 無法查證的建築（訓練場、瞭望台、圍籬）在說明裡標示為「遊戲設定」。

各族需要避開或小心處理的內容：

| 族 | 注意事項 |
|---|---|
| 共通 | 不呈現獵首、頭骨架、傷亡；神聖或有身分意義的物品不當戰利品或交易品；紋樣只用一般幾何形狀 |
| 布農 | Pasibutbut 是祈禱，演唱者有限制，不做成音效或小遊戲；多數族人不接受「八部合音」這個名稱。射耳祭祭場有禁忌，不把獵首遊戲化。小米倉與種粟屬於家族，傳統上設在屋內、外人不能進入。木刻畫曆出自卡、丹社群，不是全族共通。 |
| 阿美 | Ilisin 是祭儀不是表演，日期與規範由各部落決定。海祭等有性別限制。巫師（sikawasay）是現存的信仰，不做成法術。聚會所各地稱呼不同（'adawang、talo'an、soraratan、sefi），選定一個地區後要一致。 |
| 泰雅 | 不把紋面做成外觀或獎勵。不把 utux、彩虹橋做成能力。「頭目」是日治時期的稱呼，領袖稱 mrhuw。織布與 gaga 有關，圖案用一般條紋，不用特定命名紋樣。貝珠衣、織布機不當戰利品。太魯閣族與賽德克族是獨立的民族，內容不要混入。 |
| 排灣 | 陶壺、琉璃珠、青銅刀是貴族的傳家寶，不當交易品或戰利品。百步蛇紋、人頭紋、太陽紋是頭目與貴族專屬，不當一般裝飾；百步蛇不能當成敵人或獵物。石板屋是北、中排灣的做法，南、東排灣用木板與茅草。百合花是拉瓦爾群的習俗，不是全排灣共通。 |
| 雅美（達悟） | 文化上沒有出征的傳統，設計玩法時要留意。飛魚有嚴格的禁忌。 |
