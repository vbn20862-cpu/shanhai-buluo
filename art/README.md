## 阿美族說明
- 顏色與材質：代表色 #2F78C2 只用在裝飾條紋、旗子、人物頭帶和腰帶。厚茅草屋頂 #D6A44A（鋸齒簷口），雙色竹牆 #C2B46C，柱與架子木色 #7A5534（接點綁繩），地面淺沙色 #DCC894。明暗為暖光冷影。地景是海岸山脈、沙灘、礁岩、溪，植被用檳榔、林投、竹林，生活點景有撒網、竹筏、晾網、晾小米、野菜園。
- 待查證：聚會所屋頂形式、柱數與高度；家屋牆體比例與門的位置；穀倉柱腳是否加防鼠板、梯子形式；漁寮曬魚架、魚筌、晾網形式；巴拉告竹筒與枝條擺放方式；場景中的竹筏、撒網、背簍。訓練場、瞭望台為四族共用的通用造型。

## 泰雅族說明
- 顏色與材質：代表色 #B5483A。茅草屋頂 #C8A35A，竹牆 #A9A35C，領袖家屋原木牆 #8E6644，地面 #BFA97F。家屋與領袖家屋是半穴居，屋身半埋在土堤裡。地景是北部山林溪谷，竹林多、溪邊大石頭，望樓約 130 高。
- 紋樣：主紋壓一挑一、副紋平行條紋；織布屋晾的布只用一般條紋。
- 待查證：領袖家屋的屋身形式與半穴居深度；家屋半穴居的深度、門的位置；織布屋形式與晾布方式；穀倉防鼠板形狀；望樓的柱數、走道與頂上小屋形式。

## 布農族說明
- 顏色與材質：代表色 #3E8A62。石板牆 #868B8E，石板頂 #646A70，地面 #A89E86。屋身寬而低，屋前鋪石板地。地景是中央山脈高處：針葉林、山腰的雲、石砌擋土牆。
- 紋樣：主紋格紋、副紋粗細條紋。
- 待查證：主屋、家屋、小米倉的屋頂材質與坡度（目前畫石板頂）；獵寮與肉乾架形式；石板豬圈的高度與頂的位置。

## 排灣族說明
- 顏色與材質：代表色 #C9962B。板岩頂 #53575A，板岩牆 #7A7C78，地面 #A3998A。屋頂畫成後高前低的單坡石板頂，屋前有石砌平臺；頭目家屋前的立石為素面。地景是南部山林：闊葉樹、芭蕉、檳榔，石板路與石牆。
- 紋樣：主紋繩紋、副紋圓點。
- 待查證：石板屋屋頂坡向、門窗位置；頭目家屋前庭平臺與立石的位置比例；穀倉形式（目前為簡化造型）；芋頭窯大小、木架與竹架的搭法。

訓練場、瞭望台為四族共用的通用造型；小米田四族共用造型、換旗子紋樣。

## 第二包（2026 年 11 月更新：建築每 5 級換外觀、兵種三階）（山林亂戰、人物、新建築、升級要素）

畫法、配色、四階明暗與第一包相同。基色寫成 CSS 變數（寫在 svg 根元素的 style 裡），明暗用 f-（填色）／s-（線條）開頭的 class 搭配 color-mix 算出：

要從外部換顏色，請把 SVG 內嵌進頁面後改變數；用 <img> 載入時會顯示預設色。

### people/ 人物與兵種（四族 × 31 個）
- 畫布：viewBox="-30 -70 60 80"；英雄 viewBox="-50 -70 100 80"。原點 (0,0)＝腳底中央，面向右。頭頂約 y=-34，武器最高約 y=-62。
- 圖層：#shadow 腳下影子、#body 身體（含背負的箭袋、行囊、背簍）、#band 頭帶（含後方綁結飄帶）與腰帶（fill="currentColor"）、#weapon 矛、弓、箭、盾、扛的東西。
- 兵種三階：族群-warrior／archer／unique-stand／run／attack 為第 1 階；加上 -t2、-t3 為第 2、3 階（例：amis-warrior-attack-t3.svg）。
  - 第 1 階：素色短衣、基本武器。
  - 第 2 階：加綁腿與腰袋，矛頭與弓加大；弓手背上箭袋。
  - 第 3 階：再加深色厚麻背心與護臂，背上行囊或箭袋，武器最長。只表現裝備的多寡與實用程度，沒有身分意義的裝飾。
- 一般族人與英雄：族群-villager-a-stand、villager-a-walk、villager-b-stand、hero-stand（只有一階）。
- 可替換變數：--main 上衣（泰雅 #B5483A、布農 #3E8A62、阿美 #2F78C2、排灣 #C9962B）、--cloth 下身與帽子 #8C7356、--wrap 披布（阿美 #CDB98E、泰雅 #6E5440）、--vest 第 3 階背心與護臂 #5E4836、--leg 綁腿 #D8CBA8、--skin #B9845A、--hair #2B211B、--wood #7A5534、--tip 矛頭、弓弦、箭羽 #C9C4B4。
- 明暗的混色量寫成 --L／--LL／--D／--DD 四個變數，線條預設圓頭圓角寫在 CSS 裡（少數方頭用 style 屬性）。
- 大小：一般 3.7–7.2 KB、英雄 4–11 KB；gzip 後 1.2–2.7 KB。比原本 3 KB 的目標大，因為加了頭髮、手腳、衣褶、裝備細節。
- 獨特兵種：泰雅「山林獵手」深褐披布、短矛低持；布農「獵人」大弓、背素面箭袋；阿美「部落青年」麻色披布、雙手持矛；排灣「石牆守衛」矛＋素面圓盾。
- 族人 b：泰雅扛竹竿、布農扛柴、阿美扛掘棒、排灣提芋頭籃。英雄：泰雅「射日的勇士們」三人拿弓；布農「射日的父子」一大一小拿弓；阿美「齊心的青年們」三人手牽手；排灣「紅眼睛的巴里」寬簷帽壓低遮住眼睛，不畫眼睛、不拿武器。

- 卑南：家屋椽頭外露的方式、屋頂高度比例、前廊有沒有；tree-a 的刺竹叢形態是否符合臺東平原常見的樣子。
